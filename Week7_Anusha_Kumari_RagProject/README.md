# Week 7 - Document Question Answering System (RAG)

This project implements a Retrieval-Augmented Generation (RAG) system using LangChain, FAISS, HuggingFace Embeddings, Google Gemini, and Streamlit.

## Features
- PDF document loading
- Text chunking
- Vector embeddings using HuggingFace
- FAISS vector database
- Gemini-powered question answering
- Streamlit web interface

## Technologies Used
- Python
- LangChain
- FAISS
- HuggingFace Embeddings
- Google Gemini
- Streamlit
